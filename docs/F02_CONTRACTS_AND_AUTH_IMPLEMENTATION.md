### Transport and response decisions

No automatic retry or offline command queue is supplied. Idempotency keys are passed unchanged; feature contracts still validate each command's exact key/body/terms requirements.
- Creator writes require an in-memory `X-CSRF-Token`; staff writes use their independently supplied `x-staff-csrf`. Only the exact creator OAuth sign-in start has its mapped CSRF exemption. Guest/reader namespaces cannot use the creator client. Browser cookie matching and backend authorization still apply: audience routing is an engineering boundary, not a browser ability to choose individual same-origin cookies or an authorization guarantee.

A post-read response-size check rejects oversized JSON; it is not a streaming memory bound.
- Unexpected success statuses, invalid JSON/schema/content type and redirects are rejected. Native redirect rejection can surface as an unconfirmed network failure; it never follows or automatically replays the command. Timeout, caller cancellation, denied/not-found/conflict/throttled/unavailable and protocol errors retain distinct metadata. ### Session and private-state lifecycle

### Implementation decisions

- [Bounded SSE parser](../src/services/realtime/sse-parser.ts) incrementally decodes UTF-8 across network boundaries, including BOM, CR/LF/CRLF, comments, multi-line data, IDs and numeric retry directives. Lines and accumulated events are limited to 262,144 characters; large chunks decode in 4 KiB slices. Incomplete EOF events are discarded; invalid UTF-8 is rejected conservatively. This follows [standard SSE framing](https://html.spec.whatwg.org/multipage/server-sent-events.html#parsing-an-event-stream), with stricter size/encoding limits. It stores no event history or raw diagnostics.
- [Subscription](../src/services/realtime/overlay-subscription.ts) owns one display/grant/protocol in an overlay authority scope. It uses credentialed read-only Fetch streams, exact origin/UUID-derived paths, no redirects/cache/referrer and only validated cursors in `Last-Event-ID`. Fetch permits explicit HTTP failure classification and reader cancellation; it is not a general command or payment retry facility. Bootstrap remains an explicit feature responsibility. Stop is terminal; create a new subscription for a new lifetime. Duplicate owners are rejected without letting an unstarted object release another owner.
- V1 omits the protocol query; v2 explicitly uses `protocolVersion=2`. The [state adapter](../src/services/realtime/overlay-state.ts) delegates v1 to the pinned backend reducer. Its reviewed v2 counterpart validates complete v2 frames/events and preserves the entire template descriptor, without casts, dropped fields or legacy-style coercion. This addresses GAP-OVERLAY-V2 in the frontend adapter; the packaged backend reducer remains v1. Template availability suppresses v2 QR; renderer assets, selection UX and actual rendering remain F07/F09.
- Resource/event/wire-cursor/type/schema coherence is validated. Coherent foreign resource traffic is ignored. Duplicates/stale changes cannot renew freshness or accumulate money. Gaps, resync and contradictions hide content and request an authoritative snapshot. Version/time floors survive disconnect; late/older HTTP reads cannot overwrite newer stream state. A new gap racing an in-flight HTTP read triggers the required newer read without reconnecting the stream. No restored lower baseline is trusted within the old authority; a held restore requires the existing external epoch/new-grant procedure.
- Retry is for GET transport/authoritative reads only. Normal reconnect uses a two-second minimum, exponential delay capped at 30 seconds with jitter, and honors valid server delays up to five minutes. Longer server hints stop unavailable rather than reconnecting early. HTTP 204 stops; 401/403 deny; 404/409 and other terminal failures stop unavailable; malformed content/schema stops with a safe protocol error. Network/EOF/transient approved 429/503 can reconnect. There is no sign-in redirect, automatic protocol downgrade, grant issuance or mutation replay.
- A 15-second header deadline and 20-second silent-read watchdog prevent a silent native transport remaining open indefinitely. A 250 ms presentation timer and focus/visibility checks apply monotonic freshness/countdowns. Comments/duplicate events do not renew the validated clock. Disconnect hides content immediately; known funding cutoff hides QR without changing a server round or financial outcome. Browser scheduling is not a realtime rendering guarantee; actual OBS acceptance remains separate.
- Scope disposal/unmount stops timers, aborts snapshot/stream work, explicitly cancels the reader even if a custom fetcher ignores AbortSignal, removes temporary query entries and fences late results. HTTP snapshot reads use the authority QueryClient; the public overlay reducer owns the current stream projection, not a second ledger or accumulated event total. The optional fixture subscribes React state to the external stream and creates/disposes a fresh scope per effect, including StrictMode cleanup. No global store or browser persistence was added.
