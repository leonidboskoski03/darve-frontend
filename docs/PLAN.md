# Implementation plan

Decision: 2026-10-22, Europe/Warsaw. Build from scratch in this canonical `darve-frontend` workspace; preserve the existing backend and selected F/M/R/A visual direction. React, TypeScript, Vite, React Router, TanStack Query, React state, Tailwind/CSS tokens, Zod/public backend contracts, Fetch/SSE, Lucide, GSAP with `@gsap/react`, Framer Motion, Vitest/RTL, Playwright, ESLint/Prettier and Husky are selected.

This request authorizes the plan, architecture and skeleton. Feature batches below are a reviewable sequence, not an assertion that their implementation or external actions have been approved. Initial delivery is local; deployment prerequisites remain tracked in [OPERATIONS](OPERATIONS.md).
